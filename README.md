# Competitive Programming Solutions (C++)

Personal repository of competitive programming solutions, algorithmic challenge implementations, and data structure templates written in modern **C++**.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Language: C++](https://img.shields.io/badge/Language-C%2B%2B-blue.svg?logo=c%2B%2B)](https://isocpp.org/)

> **Note**: If you are working through these problems, try solving them on your own first! Feel free to reference these solutions if you get stuck or want to study alternative algorithmic approaches.

---

## Start with the reasoning

The [docs folder](docs/README.md) explains how the solutions in this repository work. Start with [CCC and CCCHK](docs/CCC/README.md), which covers all 21 solutions in `CCC/`. Each problem has its own README with the approach, a small example, complexity, and relevant implementation limits.

## Repository Structure

```text
.
├── Algorithms/         # Classic algorithms & data structures (DP, Union-Find, LCS, LIS, BST)
├── CCC/                # Canadian Computing Competition (Senior & Junior stages)
├── docs/               # Solution explanations, organized to match the source folders
├── IOI/                # International Olympiad in Informatics
├── LeetCode/           # LeetCode problems indexed by number and title
├── *.cpp               # Individual contest challenges (CCO, DMOPC, DMPG, DWITE, Hacker Cup)
└── LICENSE             # MIT License
```

### Categorized Archives

| Directory | Focus & Contests |
|---|---|
| [`Algorithms/`](Algorithms/) | Classic algorithms and foundational data structures (Disjoint Set Union, Coin Change, Longest Common Subsequence, Longest Increasing Subsequence, Ternary Search Tree, Backtracking) |
| [`CCC/`](CCC/) | Canadian Computing Competition solutions (CCC Junior & Senior from 1996 to present, CCCHK) |
| [`IOI/`](IOI/) | International Olympiad in Informatics problem solutions |
| [`LeetCode/`](LeetCode/) | LeetCode algorithm and data structure problems with time/space complexity focus |

Individual contest problems (e.g., Canadian Computing Olympiad `CCO`, `DMOPC`, `DMPG`, `DWITE`, `Facebook Hacker Cup`, `CTU Open`) reside at the root level.

---

All solutions are written in standard C++ and can be compiled using g++ or clang++ with C++17/C++20.
